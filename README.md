# Engineering Lab

첨부 디자인을 반영한 공학기술 소개 사이트입니다. 공개 배포하지 않았습니다.
외부 라이브러리, 원격 이미지, API 없이 동작합니다. 콘텐츠와 도해는 학습용 데모입니다.

## 로컬 실행

이 폴더에서 다음 명령을 실행하세요.

```sh
python3 -m http.server 8080 --bind 127.0.0.1 --directory dist
```

브라우저에서 http://127.0.0.1:8080 을 여세요. 종료는 Ctrl+C입니다.
서버 없이 dist/index.html을 브라우저로 열어도 사용할 수 있습니다.

## 구성

- dist/index.html: 한국어 랜딩 페이지와 SVG 터빈 도해
- dist/style.css: 반응형 디자인, 접근성 및 동작 줄이기 지원
- dist/app.js: 기술 분야 전환, 회전 속도 실험, 일시정지와 초기화

회전 실험은 속도 변화를 보여주는 시각화이며 실제 성능 시뮬레이터가 아닙니다.
